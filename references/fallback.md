# 经同意后的网上找书兜底

触发条件：本地无合适原文，微信读书无匹配、下架、权限不足或正文无法读取。先说明实际原因，询问是否尝试网上寻找 PDF/EPUB，收到同意后才开始。

1. 用书名、作者、译者、ISBN 检索，优先作者、出版社、公共图书馆、大学/机构库和公开授权书库。不用只有标题的下载站页面证明找到了全书。
2. 核对封面/版权页、作者、版本、页数或目录。只有节选、试读或其他版本时标明并让用户选择。登录、付费或权限要求交给用户决定，不自动购买。
3. 通过可访问的明确文件链接获取 PDF/EPUB，保留原文件与来源页。不运行下载到的程序、脚本或安装包。验证实际文件类型，不能把登录网页另存为 .pdf 后导入。
4. 用 ingest FILE --title TITLE --author AUTHOR --source-url SOURCE_PAGE 建立统一书库，以后本地可检索，无需重下。
5. 文字 PDF 按页提取；空白或无法提取页保留缺失记录。扫描版需要 OCR，先检查本机能力。若要把整书发送给外部 OCR 服务，说明用途并取得同意，不默认上传。没有可用 OCR 时明确需要文字版或 OCR 后文件。
6. 核对导入覆盖和关键段落后解读。保留原 PDF 页序作为出处，不把它伪装成纸书印刷页码。

仍无可信、可访问原文时，报告实际找到的资料和缺失，允许用户提供自己的文件。简介、书评、远端 AI 回答只能作为注明来源的辅助资料，不能进入正文缓存。
